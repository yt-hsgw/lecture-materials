1.

Excel って 何？

数字の 方眼紙

マス目を セル と 呼びます。 1つ1つのセルに 名前（住所）が ついています。
列の文字 ＋ 行の数字 で セルを 呼ぶ。 例：B2

ABC
1A1
2B2
3C3

「A1」 ＝ A列 の 1行目／「B2」 ＝ B列 の 2行目／「C3」 ＝ C列 の 3行目

💡 名前 を 覚える 必要 は ない

クリック すれば 自動で 選ばれます。 名前は 「計算式の中で 場所を 言う」 ときに 使います！

2.

ライブ 表計算（本物の Excel風）

クリックして 数字を 入れて みよう

セルを クリック → 文字や 数字を 打って Enter。
=SUM(B2:B6) のような 数式 も 本物と 同じように 動きます！

A1 = クリックで セルを 選ぶ

💡 数式の 書き方

セルに =A1+B1 や =SUM(B2:B6) と 入力すると 自動計算！
数式は 必ず = から 始める。

3.

数式 辞典

覚えると ラクな 4つ

カードを 押すと 詳しい 使い方が 表示されます。 全部 ＝ から 始める！

📐 算術の 記号

+ 足す ／ - 引く ／ * かける（×ではない！）／ / わる（÷ではない！）
例：=10*5 → 50 ／ =A1/B1 → A1 ÷ B1

4.

グラフ で 見える化

数字 → グラフ → 一目瞭然

上の 家計簿の データ（B列の数値）から、 棒グラフ と 円グラフを 自動生成。

💡 グラフ の 選び方

棒グラフ：項目を 比べる（食費 vs 光熱費）
円グラフ：割合 を 見る（全体の何％？）
折れ線：時間の 変化（1年の体重）

5.

家計簿 テンプレート

入力するだけ — 印刷 OK

月名と 5項目の 金額を 入れると、 きれいな 家計簿 が 完成！
「印刷」 で 紙に 出して、 冷蔵庫に 貼って 使えます。

6.

安全 の ひと言

家計簿 に 入れない もの

⚠️ 危ない 情報

  • 銀行口座 の 番号
  • クレジットカード 番号
  • 暗証番号 ／ パスワード
  • マイナンバー

💡 大事なファイル は パスワード

Excel の ファイル → 情報 → ブックの保護 → パスワードを使用して暗号化。
⚠️ パスワードを 忘れたら 開けない！ メモを 別の場所 に！

7.

たしかめ クイズ

3問 やってみましょう

気軽に 試して くださいね。 何回 間違えても 大丈夫です。

Q1. B列 の 2行目 の セル の 名前 は？
✅ 「列の文字 ＋ 行の数字」の順。 B列の2行目 ＝ B2。 住所みたいに 覚える！
Q2. 5つの セル（B2 〜 B6）の 合計 を 一発で 出す 数式 は？
✅ =SUM(B2:B6) が 一番ラク！ : は「〜から〜まで」の意味。 ① も正解だが、 数が多いと 大変。
Q3. Excelで かけ算 の 記号 は？
✅ 半角の アスタリスク（*）。 キーボードの右上、 数字の 8の 上！ ×（バツ）や ＊（全角）は ダメ。
