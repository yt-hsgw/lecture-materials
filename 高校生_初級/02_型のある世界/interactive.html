01.

TypeScript 型推論 Playground

体感

変数 から TS が 推論 する 型

左 に JS / TS コード を 書く と、 右 に **TypeScript が 推論 した 型** が 表示 されます。 「`let x = 1`」 と 書くだけ で `number` と 推論 される 様子 を 体感。

プリセット:

💡 ポイント

`const` で 宣言 すると **リテラル型**（`"Alice"`）に、 `let` だと より 広い 型（`string`）に なる。 関数 の 引数 に 型注釈 が ない と `any` 推論。

02.

Zod で ランタイム 検証

ハンズオン

外部入力 を スキーマ で ガード

左 に **検証 する JSON**、 右 に **Zod スキーマ**。 「検証」 ボタン で 通過 / 失敗 と 不一致 の 詳細 が 表示。 API レスポンス や フォーム入力 を 安全 に 扱う 練習。

03.

any vs unknown

体感

「型 OFF」 と 「型 ON」 の 差

同じ 操作 を `any` と `unknown` で 試す と 結果 が 違う。 入力 を 変えて 「危ない 操作」 が `unknown` 側 で コンパイル エラー に なる 様子 を 体感。

❌ any

const data: any = JSON.parse(input);
console.log(data.name.toUpperCase());
//          ^^^^^^^^^^^^^^^^^^^^^^^
//          コンパイル チェック なし
//          実行 で 落ちる かも
クリック で 検証

✅ unknown

const data: unknown = JSON.parse(input);
if (typeof data === "object" && data &&
    "name" in data && typeof data.name === "string") {
  console.log(data.name.toUpperCase()); // ✅
}

05.

クイズ で ふり返ろう

3問チャレンジ

Q1. TypeScript の `type X = { id: string }` は **何時点** で 効く？
💡 TS の 型 は コンパイル時 に 消える。 ランタイム の バリデーション は **Zod / Pydantic** が 担当。
Q2. `any` と `unknown` の **違い** は？
💡 `any` は チェック 全 OFF（バグ温床）、 `unknown` は 「未知 だから 触れない」 ＝ コンパイラ が 守ってくれる。
Q3. Discriminated Union（識別共用体）の **メリット** は？
💡 `kind` フィールド で 分岐 する と、 switch で 全 ケース 網羅 しない と 型エラー。 仕様変更 で ケース 追加 した 時 も 即発見。
