# 高校生プログラミング塾 ／ 初級コース

## このコースのゴール

中学生・上級 までで「設計 → 実装 → テスト → 公開 → 運用」のサイクルを 体験した 高校生が、**実務に近い 開発スキル** を身につける。インターン・アルバイト・個人開発を 一段プロっぽく できるレベル。

- **モダンな 開発環境** を 自分で 構築できる（VSCode / Docker / WSL / dotfiles）
- **型のある世界**（TypeScript / Python型ヒント） を 当たり前に 書ける
- **テスト駆動開発（TDD）** の リズム を 体得する
- **アジャイル と Issue 駆動** で チームの 一員として 動ける
- 「動けば OK」から 「**保守可能な コードを 速く 書く**」へ ステップアップ

> 中学生・上級 が「他人と 一緒に 作って ちゃんと 運用する」だったのに対し、高校生・初級 は **「実務で 通用する 速度と 品質」** を 主役にします。インターン・短期アルバイトでも 即戦力に 近づくのを 狙います。

## 本編スケジュール（全4回・各90〜120分）

| 回 | タイトル | テーマ | ハンズオン |
|----|---------|--------|----------|
| 1 | 開発環境のプロ仕様 | VSCode / Docker / WSL / dotfiles / Git Hooks | dev container 1個 立てる |
| 2 | 型のある世界 | TypeScript / Python型ヒント / Pydantic / Zod | 既存JSをTSに変換 |
| 3 | テスト駆動開発（TDD）実践 | jest / pytest / カバレッジ / モック | red-green-refactor を 1機能で |
| 4 | アジャイルとIssue駆動 | GitHub Issues / Projects / Scrum / 見積もり | スプリント計画 → 振り返り |

---

## 各回の狙い

### 第1回｜開発環境のプロ仕様
中学生・中級 で 触れた「VSCode + Git」を プロが 使う レベルへ。**Docker / WSL2 / dotfiles / pre-commit** で 自分の 環境を コード化する。 PC 入れ替えても 30分で 同じ環境を 再現できる ようにする。

### 第2回｜型のある世界
動的型言語（JS / Python）の 自由さの 裏側に ある コスト を 体験。 既存の JS ファイルを TypeScript に 段階的に 移行し、 Python では `mypy` + `Pydantic` で 同等の 安心感 を 得る。

### 第3回｜テスト駆動開発（TDD）実践
中学生・上級 で 触れた 「テストを 先に 書く」 を、 ちゃんと **赤 → 緑 → リファクタ** の リズムで 体に 染み込ませる。 jest / pytest / カバレッジ計測 / モック を 1機能で 通す。

### 第4回｜アジャイルとIssue駆動
**GitHub Issues + Projects** で プロジェクトを 動かす。 スプリント計画・デイリースタンドアップ・レトロスペクティブ を ペーパーで 体験。 「人間が 計画して 人間が 振り返る」 を 1サイクル。

## 設計方針

- **動く 環境を コード化**：環境構築は README ではなく Dockerfile / devcontainer.json
- **CI に 失敗させて 学ぶ**：lint / type / test で 不合格 になる 経験を 故意に 作る
- **AI は ペアプロ相手**：Copilot / Cursor を 前提に、 でも 「読めて 説明できる」 を 保つ
- **小さく 何度も**：1日 1コミット ではなく、 1機能 = 1PR の 粒度
- **公開を 前提に**：README / LICENSE / .gitignore は 最初に 整える

---

## 危険ケース・注意

- **ライセンス違反**：OSS の MIT / Apache / GPL の 違いを 知らずに コピペ
- **秘密情報の 公開**：`.env` を コミット、 API キーを ハードコード
- **Docker の ディスク逼迫**：放置 image / volume で 数十 GB
- **WSL2 の パフォーマンス**：Windows 側 ファイルシステム への アクセスは 遅い
- **過剰な 抽象化**：型・テスト・パターンを 「使うため」に 使う 罠

---

## 中学生・上級との 差分メモ

- 中学生・上級：「ローカルで 動けば 公開」 ／ 高校生・初級：**「環境を 再現可能に コード化」**
- 中学生・上級：「テストを 1回 書いてみる」 ／ 高校生・初級：**「TDD の リズムを 体得」**
- 中学生・上級：「型は 任意」 ／ 高校生・初級：**「型が 当たり前」**
- 中学生・上級：「個人 PR」 ／ 高校生・初級：**「Issue 駆動 + 見積もり」**
