03.

dotfiles リポジトリ 設計

ハンズオン

個人設定 を Git管理 する 構成

含めたい 設定 を 選ぶ と ディレクトリ 構成 が 生成される。 秘密情報 を 選択 すると 警告 が 出るので、 必ず 除外 を 学ぼう。

⚠️ .ssh/id_rsa（秘密鍵）や .env（API キー）を 含めて は いけません。 GitHub に push すると 即座 に 漏洩 します。 .gitignore で 必ず 除外。
04.

pre-commit の 動き

ハンズオン

コミット前 に 自動 チェック

下 の コード に わざと エラー を 入れて 「コミット 実行」 ボタン を 押そう。 lint / format / 秘密情報検出 が 走る 様子 を 再現します。

05.

クイズ で ふり返ろう

3問チャレンジ

Q1. 環境構築 が README ベース だと 起こりやすい 問題 は？
💡 Dockerfile に すると 暗黙の 前提 が 全部 明示され、 CI が 失敗 する ので 古く ならない。
Q2. dotfiles リポジトリ に **含めて は いけない** ものは？
💡 秘密鍵・API キー・パスワード は 絶対 NG。 GitHub に push した 瞬間 に 世界中 に 公開。
Q3. pre-commit が 走る タイミング は？
💡 pre-commit ＝ commit の 「pre」（直前）。 lint / format / 秘密検出 を フックして、 通らなければ commit できない。
