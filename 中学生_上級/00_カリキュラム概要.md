# 中学生向けプログラミング塾 ／ 上級コース

## このコースのゴール

中級で「Webアプリを設計→実装→公開」までできた中学生が、**本格的なソフトウェア開発の一周** を経験する。

- **要件定義 → 設計 → 実装 → テスト → リリース → 運用 → 改善** の流れを体験
- **データベース** を使って 永続化（SQLite / PostgreSQL）
- **認証**（ユーザーログイン）の基本を理解する
- **セキュリティ** の最低限（入力検証・XSS対策・秘密情報管理）
- **チーム開発**（Gitブランチ・プルリクエスト・コードレビュー）

> 中級が「自分1人で動くものを作る」だったのに対し、上級は **「他人と一緒に作って、ちゃんと運用する」** を主役にします。高校生 / 専門学校 / 大学のプログラミング授業の橋渡しになる粒度。

## 本編スケジュール（全4回・各60〜90分）

| 回 | タイトル | テーマ | ハンズオン |
|----|---------|--------|----------|
| 1 | 要件定義と設計 | ユースケース／DB設計／画面設計／チーム分担 | チームで企画書を作る |
| 2 | 実装とレビュー | DB／認証／APIの実装／プルリクエスト | ペアで実装＋レビュー |
| 3 | テストとリリース | ユニットテスト／結合テスト／デプロイ | 公開できる状態に |
| 4 | 運用・改善・マネタイズ概論 | ログ／監視／フィードバック／法務 | 公開後の改善計画 |

---

## 各回の狙い

### 第1回｜要件定義と設計
題材は **「みんなの感想記録アプリ」** や **「学校行事カレンダー」** など、教室で実用できそうなもの。**ユーザーストーリー → 画面 → DBスキーマ** の順で 紙ベースで設計。

### 第2回｜実装とレビュー
**ペアまたはチーム** で実装。**Git のブランチを切って → プルリクエスト → コードレビュー → マージ** のフロー を体験。AI レビューも併用。

### 第3回｜テストとリリース
**ユニットテスト**（pytest / Jest）の基本、**手動テストシナリオ**、そして **Render / Vercel / Cloudflare Pages 等** にデプロイ。

### 第4回｜運用・改善・マネタイズ概論
公開後の **アクセスログ／フィードバック収集**、**バグ修正** の優先順位。最後に **マネタイズ／著作権／個人情報保護法／利用規約** の概論を 子どもの言葉で。

## 設計方針

- **チーム開発の作法**：プルリクエスト・コードレビュー・コミットメッセージ
- **テスト駆動の入り口**：「テストを先に書く」 を 1 回でも体験
- **セキュリティ最低限**：OWASP Top10 の入力検証・認証・秘密情報管理
- **公開と責任**：公開する＝他人の時間を奪う可能性、を意識
- **AIは最強の補助**：ただし「読めて、説明できる」を保つ

---

## 危険ケース・注意

- **APIキー流出**：環境変数 / `.env.example` の概念を必ず教える
- **個人情報の取扱い**：実ユーザー情報を扱うなら 学校・保護者・教室の事前同意
- **公開時の責任**：未成年が公開するサービスの責任主体は保護者
- **マネタイズの注意**：13歳以上の規約、税・確定申告、保護者同意（収益発生時）
- **著作権**：他人のコード／画像／音をコピペするときの出典
- **過熱**：実装にハマりすぎて テスト・ドキュメントを軽視しないように
