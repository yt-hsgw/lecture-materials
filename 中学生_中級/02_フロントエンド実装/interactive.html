    Q1. JS から HTML 要素を 取得する 万能 な 方法は？
    
      
    
        
        
        
        
      
    
      
    ✅ querySelector() は CSSセレクタ で 探せる万能関数。 '#id' も '.class' も 'tag.class' も OK。 複数取得は querySelectorAll()。
    
    
    

    
    
      
    Q2. ユーザー入力を 画面に 出すとき 安全 なのは？
    
      
    
        
        
        
        
      
    
      
    ✅ textContent は そのまま テキスト として表示。 innerHTML は HTML として 解釈されるので、 入力に <script> が 入ると 実行されちゃう（XSS）！
    
    
    

    
    
      
    Q3. localStorage に オブジェクトを 正しく 保存する 方法は？
    
      
    
        
        
        
        
      
    
      
    ✅ localStorage は 文字列だけ 保存できる。 オブジェクトは JSON.stringify() で 文字列化、 読むときは JSON.parse() で 戻す！
