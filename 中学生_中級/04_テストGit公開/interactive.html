07.

たしかめクイズ

4問 やってみよう

答えがわかったら 解説が出ます。

Q1. Git の 3層モデル の 正しい流れは？
✅ git add でステージへ、 git commit でリポジトリへ。 直接 ジャンプ できない 3層モデル！
Q2. .env ファイルを 絶対に やってはいけない 行為は？
✅ .env には APIキー など 秘密情報。 commit → push したら 履歴に 残り、 GitHub から 見える！ .gitignore に 必ず 入れる。
Q3. Flask アプリを 無料で 公開 する のに 向いている サービス は？
✅ GitHub Pages は 静的サイト 専用。 Flask の 動的な サーバーは Render / Railway / Vercel など。
Q4. 良い コミットメッセージ は？
✅ 動詞 + 何を どうしたか。 半年後の 自分でも わかる 言葉に。 「fix bug」 より 「タイマーが 0で止まらないバグを 修正」 の方が ベター！
