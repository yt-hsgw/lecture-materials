# 中学生向けプログラミング塾 ／ 中級コース

## このコースのゴール

初級で「自分で書いて動かす」までできた中学生が、**小さなWebアプリを設計→実装→テスト→改善する流れを 一周する**。

- **HTML/CSS/JavaScript** で動的なWebページを作れる
- **Python の Flask** または **Node.js の Express** で **ローカルサーバー** を立てられる
- **配列・オブジェクト・関数** を組み合わせて、データ操作を実装できる
- **デバッグ**（ブラウザDevTools / print文）で原因を切り分けられる
- **Git の init / add / commit / push** で バージョン管理できる

> 初級が「文法を覚える」だったのに対し、中級は **「設計の質を上げる」「再利用できる形に書く」** を主役にします。

## 本編スケジュール（全4回・各60〜90分）

| 回 | タイトル | テーマ | ハンズオン |
|----|---------|--------|----------|
| 1 | アプリの 設計 | 要件定義／画面設計／データ設計 | TODOアプリの企画書 |

| 3 | バックエンド入門 | サーバー／API／JSON | Python Flask で API |
| 4 | テスト・Git・公開 | デバッグ／Git／デプロイ概論 | コミット → 共有 |

---

## 各回の狙い

### 第1回｜アプリの 設計
**「ユーザーは誰？ 何ができる？」** を3行で定義し、**画面の絵（ワイヤフレーム）** と **データ構造（タスク = id + 内容 + 完了フラグ）** を 紙とエンピツで設計。

### 第2回｜フロントエンド実装
HTML で骨組み、CSS で見た目、JavaScript で **追加／削除／チェック** を実装する。`querySelector` `addEventListener` `localStorage` まで。

### 第3回｜バックエンド入門
**Flask** で `GET /api/tasks` `POST /api/tasks` の最小サーバーを書く。フロントエンドから `fetch()` で呼び出して、データの 永続化を体験。

### 第4回｜テスト・Git・公開
DevTools の Console / Network でデバッグ。**Git init → add → commit** の基本フロー。GitHub Pages や Render など **無料公開サービス** を見る（実際の公開は任意）。

## 設計方針

- **設計から始める**：いきなりコードを書かない。紙の上で1回考える
- **「動く → きれいに → 速く」の順**：まず動かす、そのあと整える
- **コードレビュー文化**：毎回1個ずつ、お互いのコードのいい点を言う
- **デバッグを見せる**：先生も詰まる場面をライブで見せる
- **AIはレビュー役**：書かせきらず、提案を1つ採用するスタイル

---

## 危険ケース・注意

- **APIキー・パスワード**：絶対に Git にコミットしない（`.env` の概念）
- **個人情報**：TODOアプリのサンプルデータに 本名・住所を入れない
- **公開時のリスク**：GitHub Pages 公開は **保護者同意 + 講師レビュー** を経てから
- **依存パッケージ**：教室で `npm install` できるか事前確認
- **時間管理**：実装で詰まると延びがち。**「動くもの」を優先**、改善は次回
