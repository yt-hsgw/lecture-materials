06.

  
CORS の 壁






  
「別の オリジン だと 拒否」 を 解決

  
CORS = Cross-Origin Resource Sharing。 別ポート の Flask に fetchすると 出る エラー。


  

    

      
🚫 拒否される パターン

      

// フロント: localhost:3000
await fetch('http://localhost:5000/api/tasks');
// → CORSエラー
      

    

    

      
✅ Flask 側で 許可

      

# app.py
from flask_cors import CORS

app = Flask(__name__)
CORS(app)  # これだけ
      

    

  


  

    
💡 オリジン (Origin) とは

    
scheme + host + port の組み合わせ。

    http://localhost:3000 と http://localhost:5000 は 別オリジン！

  







  
07.

  
たしかめクイズ






  
4問 やってみよう

  
答えがわかったら 解説が出ます。

  

    

      
Q1. 「タスク 一覧を 取得」 に 適切な メソッドは？

      

        
        
        
        
      

      
✅ GET は「取得」専用。 副作用がない（呼んでもデータが変わらない）ので 何度呼んでもOK。

    


    

      
Q2. Flask で「成功時に新しい task を JSON で返し、ステータスは 201」 と したい：

      

        
        
        
        
      

      
✅ Flask は (body, status_code) のタプル を 返せる。 201 Created は新規作成成功の 慣例。

    


    

      
Q3. fetch で POST する とき 必須 なのは？

      

        
        
        
        
      

      
✅ method:'POST'、 headers:{'Content-Type':'application/json'}、 body:JSON.stringify(data) の 3点セット。 headers を 忘れると サーバーが JSON と 認識できない！

    


    

      
Q4. http://localhost:3000 から http://localhost:5000 に fetch → エラー。 原因は？

      

        
        
        
        
      

      
✅ ポート番号 が 違う＝別オリジン。 Flask 側で from flask_cors import CORS; CORS(app) で 許可！
