05.

クイズ で ふり返ろう

3問チャレンジ

Q1. CI を 「lint と test と build を 同じ ジョブ」 に まとめる **デメリット** は？
💡 分けると どの ジョブ が 失敗 か UI で 一目、 並列 で 短時間、 失敗 だけ 再実行 可。
Q2. **アラート 疲れ** を 防ぐ ベスト プラクティス は？
💡 症状 ではなく **影響** に 鳴らす。 「CPU 高い」 だけ では ユーザー に 問題 が 出ているか 不明。
Q3. ログ を 「文字列 連結」 で 書く **問題** は？
💡 構造化 ログ（JSON）で {userId, event, level} を 持つ と Datadog / CloudWatch で 集計 / アラート / トレース 可能。
