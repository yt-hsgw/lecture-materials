ハンズオン ② サーバーから来たページの「中身」を見る

どんなブラウザでもできるよ。やってみよう！

  1. すきなWebサイトをひらく
  2. ページのなにもないところで みぎクリック
  3. 「ページのソースを表示」（または「View Source」）をえらぶ
  4. たくさんのもじが出てくる ＝ それが HTML！
<html>
  <head>...</head>
  <body>...たくさんのもじ...</body>
</html>

✨ これがサーバーから届いた、本物のWebページの正体！

ハンズオン ③ 開発者ツールで「リクエスト」を見る

パソコンでやろう（スマホはむずかしい）

  1. キーボードの F12 をおす（Macは ⌘＋⌥＋I）
  2. 下や右に「開発者ツール」がひらく
  3. 「Network」タブをクリック
  4. ページを もう一度よみこむ（F5）
  5. たくさんの「リクエスト」がながれてくる！

💡 「ほんとうにサーバーとお話してた」が見える、すごい瞬間！
