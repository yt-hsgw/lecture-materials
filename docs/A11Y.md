## 基本方針

- **教材 ＝ 公共物**。 視覚障害・聴覚障害・身体障害・色覚多様性 のある 受講者 が 利用可能 で あるべき
- **「色だけ」 で 情報を 伝えない**：✓ アイコン や テキスト ラベル を 併用
- **キーボード だけ で 全操作 可能**：マウス 必須 を 作らない
- **スクリーンリーダー 利用者 にも 情報 が 届く**：意味的 マークアップ + ARIA 補助
- **既存 利用者 を 犠牲 にしない**：シニア向け 拡大文字、 子ども向け 直感UI など コース特性 は 維持

## チェックリスト

新規 / 既存教材 を リリース前 に 確認。

### 構造

- [ ] `<html lang="ja">` が ある
- [ ] `<title>` が ページ内容 を 表す
- [ ] 見出し階層 が 飛び級 していない（h1 → h2 → h3）
- [ ] `main` / `nav` / `header` / `footer` 等 の ランドマーク が 適切

### 画像 / メディア

- [ ] 全 `<img>` に `alt` 属性（装飾なら `alt=""`）
- [ ] 動画 に 字幕 / トランスクリプト（教材動画 を 追加する 場合）
- [ ] 自動再生 / 自動回転 は **5秒以内 で 止められる**

### 色 / コントラスト

- [ ] 本文 と 背景 の **コントラスト比 4.5:1 以上**（WCAG AA）
- [ ] 大型テキスト（18pt 以上 / 14pt太字 以上）は **3:1 以上**
- [ ] 「成功 / 警告 / エラー」 を **色だけ** で 表現しない（アイコン / 文字 併用）
- [ ] フォーカス リング（`:focus`） が 視認可能 な コントラスト

### キーボード

- [ ] **Tab キー だけ** で 全 インタラクティブ要素 を 巡回 可能
- [ ] フォーカス 順序 が 論理的（DOM 順 と 一致）
- [ ] **Esc** で モーダル を 閉じられる
- [ ] **Enter / Space** で ボタン が 動作
- [ ] **キーボード トラップ** が ない（タブ で 抜け出せる）

### フォーム

- [ ] 全 `<input>` `<select>` `<textarea>` に **ラベル**（`<label for>` / `aria-label` / `placeholder`）
- [ ] エラー メッセージ が **入力欄 と 関連付け**（`aria-describedby`）
- [ ] 必須項目 が 明示

### インタラクティブ要素

- [ ] **アイコン専用 ボタン** に `aria-label` または `title`（×、←、→、？ など）
- [ ] **リンク / ボタン** の テキスト が **行動 を 表す**（「クリック」 ではなく 「次の問題へ」）
- [ ] **複雑な ウィジェット**（タブ / アコーディオン）に `role` + `aria-*`

### 動的コンテンツ

- [ ] **トースト / アラート** は `aria-live="polite"` または `role="status"`
- [ ] **モーダル開閉時** に フォーカス が 適切 に 移動
- [ ] **タイマー / 紙吹雪** で **発作リスク**（強い 点滅 1秒3回 超）を 避ける

## 自動チェック

CI（GitHub Actions）で 以下 を 走らせて います。 ローカル でも 実行 可能。

```bash
# 全HTML の id 重複 検出
node scripts/check-id-duplicates.mjs

# 全HTML の 静的 a11y チェック（lang / img alt / input label / icon-only button / link）
node scripts/check-a11y-static.mjs

# HTML 構文 検証（html-validate）
npx html-validate --config scripts/html-validate.config.json '**/*.html'
```

`check-a11y-static.mjs` は **warning ベース**。 CI を 落とさないが PR コメント に 出る。

## 既知のwarning と対処

2026-05時点 で 残っている a11y warning と、 ガイドライン:

### 1. インタラクティブ ツール内 の `<input>` ラベルなし（約 79件）

**例**: ライブ HTML エディタ、 色ラボ、 SQL プレイグラウンド、 電卓 等 の `<input type="text">` / `<input type="color">` / `<input type="range">` で `placeholder` / 隣接 ラベル のみ。

**対処（漸進）**:

```html
<!-- Before -->
<input type="text" id="username">

<!-- After -->
<label for="username" class="visually-hidden">ユーザー名</label>
<input type="text" id="username" aria-label="ユーザー名">
```

新規教材 では 必ず `<label>` か `aria-label` を 付与。

### 2. アイコン専用 `<button>`（約 6件）

**例**: 電卓 / クイズ ナビ の `← → × * ＊` 等。

**対処**:

```html
<!-- Before -->
<button onclick="clear()">×</button>

<!-- After -->
<button onclick="clear()" aria-label="クリア">×</button>
```

**modal-close**（`×` ボタン）は **全39ファイル** で `aria-label="閉じる"` 付与済み（2026-05）。

### 3. `<img>` alt なし

現状 0件（CI で 検出 した 例は 全て JS 文字列 / 教材内 サンプル コード で 誤検出）。
**新規 `<img>` は 必ず `alt` 必須**。

## 対象別 の 配慮

各 コース で 想定 する 受講者 特性 に 応じた 追加 配慮。

### 小学生

- **絵文字 + テキスト** で 二重 表現（読めない 漢字 でも 推測 可能）
- 文字サイズ **28px 以上** 推奨
- アニメ は **派手すぎない**（集中阻害）
- 「失敗」 を 否定的 に 見せない（赤い × の 大きさ を 抑える）

### 中学生

- 用語 を 正確に（フリガナ は 必要 最小限）
- インタラクティブ ツール の **キーボード操作** を 標準化
- AI / Git / SQL 等 の 専門用語 は 必ず 初出時 に 説明

### 高校生

- 実務 で 出会う UI（Tailwind / shadcn/ui） と 同等 の a11y
- API ドキュメント へ の リンク に 「外部 リンク」 アイコン

### 高齢者

- 本文 **30〜34px**、 行間 **1.8〜1.9**
- ボタン サイズ **44×44px 以上**（タップ領域）
- コントラスト **7:1 以上**（WCAG AAA 目標）
- アニメ は **最小限**、 自動切り替え なし
- フォーカス リング を **太く**（4px 推奨）

## 手動検証 ツール

定期的に 以下 で 検証 することを 推奨:

| ツール | 用途 |
|---|---|
| **axe DevTools**（Chrome拡張） | WCAG 違反 を 自動検出 |
| **WAVE**（Web版） | 視覚的 に 問題箇所 を ハイライト |
| **Lighthouse**（Chrome DevTools） | Accessibility スコア を 数値化 |
| **NVDA**（Windows）/ **VoiceOver**（macOS） | スクリーンリーダー で 実体験 |
| **Tab キー だけ** で 全操作 | キーボード ナビゲーション 検証 |
| **カラー コントラスト アナライザー** | 配色 検証 |

### Lighthouse スコア 目標

- **Performance**: 90+
- **Accessibility**: **95+**
- **Best Practices**: 95+
- **SEO**: 90+

### axe DevTools 実行 手順

1. Chrome 拡張 「axe DevTools」 を インストール
2. 対象 HTML を 開く
3. DevTools → axe DevTools タブ → 「Scan ALL of my page」
4. **Critical / Serious** は 必ず 修正、 **Moderate / Minor** は ベスト エフォート
