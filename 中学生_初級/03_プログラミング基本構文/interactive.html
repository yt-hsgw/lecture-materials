1.

変数

値に名前をつけて、使い回す

▶ 実行 を押すと結果が見える。サンプルを切り替えてみよう。

① 基本

price = 120
count = 8
total = price * count
print(total)
$ python3 sample.py
（▶ 実行 を押すと結果が出ます）

price と count に値を入れて、total で計算する。

② 値を変えて再計算

price = 200
count = 5
total = price * count
print(price, "円 ×", count, "個 =", total, "円")
$ python3 sample.py
（▶ 実行 を押すと結果が出ます）

変数を使えば、値を1か所変えるだけで全体の計算が変わる。

2.

条件分岐

「もし〜なら」 で動きを変える

① if / else

score = 75
if score >= 80:
    print("合格！")
else:
    print("もう少し")
$ python3 sample.py
（▶ 実行）

: の後はインデント（半角スペース4つ）。

② elif で 3 つ以上の枝

score = 75
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("もう少し")
$ python3 sample.py
（▶ 実行）

上から順に判定 → 最初に当たった枝だけ実行される。

3.

繰り返し

同じことを 何回も

① for ＋ range

for i in range(5):
    print(i, "回目")
$ python3 sample.py
（▶ 実行）

range(5) は 0〜4 の5回。range(1,6) なら 1〜5。

② リストを for で回す

fruits = ["りんご", "みかん", "バナナ"]
for fruit in fruits:
    print(fruit, "が好き")
$ python3 sample.py
（▶ 実行）

リストの要素を1つずつ取り出す Python らしい書き方。

③ while

count = 0
while count < 3:
    print("カウント:", count)
    count = count + 1
$ python3 sample.py
（▶ 実行）

条件が False になるまで続く。無限ループに注意！

4.

関数

まとまりに名前をつけて 再利用

① 関数を定義して呼ぶ

def greet(name):
    print("こんにちは、" + name + "さん！")

greet("ゆうた")
greet("はるか")
$ python3 sample.py
（▶ 実行）

def 関数名(引数): で定義 → 何度でも呼び出せる。

② return で値を返す

def add(a, b):
    return a + b

result = add(3, 4)
print(result)
$ python3 sample.py
（▶ 実行）

入力 → 計算 → 結果を返す。これが関数の3点セット。

5.

FizzBuzz チャレンジ

条件の "順番" を選んで 完成させる

下のドロップダウンに正しい数字を入れて、「▶ 実行 ＆ 採点」を押すと、結果が判定されるよ。

📋 ルール

1〜15 を順に表示。3の倍数なら Fizz、5の倍数なら Buzz、両方の倍数（15の倍数）なら FizzBuzz。

📝 コードを完成させて

for i in range(1, 16): if i % == 0: print("FizzBuzz") elif i % == 0: print("Fizz") elif i % == 0: print("Buzz") else: print(i)

💡 ヒント

「より厳しい条件から」を意識すると、上から順に正しい結果になる。15は3でも5でも割り切れるから、最初に判定 しないと "Fizz" で当たって "FizzBuzz" まで届かない。
