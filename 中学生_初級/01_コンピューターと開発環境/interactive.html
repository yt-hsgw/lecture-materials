1.

コンピューターの役者紹介

4 つの役者

カードをクリックすると、それぞれの役割が見えるよ。

🧠

CPU

計算する人

秒間に何十億回もの計算を実行。プログラムの命令を一つひとつ解釈して動かす。"何GHz" はざっくり「1秒に何回計算できるか」のヒント。
📋

メモリ (RAM)

作業机

いま動いているアプリやデータを一時的に置く場所。広いほど同時に多くのことができる。電源を切ると中身は消える。
📚

ストレージ

本だな

SSDやHDD。ファイル・写真・OS本体を保管する場所。電源を切っても残る。SSDのほうが圧倒的に速い。
🪟

OS

店長

Windows / macOS / Linux など。アプリ・ファイル・ユーザー・ハードウェアの間を取り持つ。OSの上で君のプログラムも動く。

3.

エディタと実行環境

「書く」と「動かす」は別の道具

エディタはコードを書く道具、実行環境はコードを動かす道具。

✏️ エディタ（書く）

VS Code、Vim、Notepad++ など。色分け・補完・エラー検知でミスを減らす。

⚙️ 実行環境（動かす）

Python、Node.js、Java など。書かれたコードを解釈して実行する。

💡 なぜ別なの？

分かれていると、好きなエディタを選べる、複数の言語を同じエディタで書ける、エディタを変えても動かし方は同じ — みたいに、組み合わせの自由がきく。

4.

コードを動かしてみよう

Python コード「読み解き」プレイグラウンド

サンプルを切り替えて、コードを読んでから「▶ 実行」ボタンで結果を確認。実機がない場合の予習にも使えるよ。

📝 hello.py

print("Hello, World!")

⚙️ ターミナルの出力

$ python3 hello.py
（▶ 実行 を押すと結果が出ます）

最初は print("Hello, World!") から。実行してみよう。

5.

エラーを読む練習

エラーは敵じゃなくて味方

エラーメッセージは「どこ」「何」「どう」の3点でできてる。下のカードをクリックすると正解が見える。

File "hello.py", line 1 print("Hello, World!" ^ SyntaxError: '(' was never closed
① どこ？
hello.py の 1 行目。
"File ... line 1" の部分。
クリックしてこたえを見る
② 何？
SyntaxError（構文エラー）。
Pythonの文法に従っていない。
クリックしてこたえを見る
③ どう直す？
"(" が閉じられていない。
行末に ) を足す → print("Hello, World!")
クリックしてこたえを見る

💡 毎回この3つを声に出す

3週間続けると、英語のエラーでも怖くなくなる。「読めない」と「読み慣れていない」は違う。
