1.

変数で スコアを 表示

変数＝「数を覚えるハコ」

下のボタンを押すと、ハコの中の数が変わるよ。Scratchの「変数」も同じ仕組み！

スコア
0

🐹 モグラ：クリックで +1 のスクリプト

🟡 このスプライトが クリックされたとき 🟪 Pop の音を 鳴らす 🟧 スコア を 1 ずつ変える 🟣 隠す

🐹 スタート時：スコアを 0 にリセット

🟡 旗が押されたとき 🟧 スコア を 0 にする 🟣 隠す 🟠 ずっと ↓
🔵 ランダムな位置 へ移動する 🟣 表示する 🟠 1秒 待つ 🟣 隠す

💡 リセットを忘れない

スタート時に 必ず 0 に戻す。じゃないと前回のスコアが残ったまま！

2.

タイマーで 時間制限

ステージの スクリプトで タイマー

タイマーはステージ（一番右下の青い四角）に書くのが分かりやすい。

🟡 旗が押されたとき 🟧 のこり時間 を 30 にする 🟠 ずっと ↓
🟠 1秒 待つ 🟧 のこり時間 を -1 ずつ変える 🟠 もし のこり時間 = 0 なら ↓
🟡 「ゲーム終了」を送る 🟠 すべてを止める

💡 「メッセージを送る」 ＝ スプライト同士の呼びかけ

ステージから 「ゲーム終了」 を送ると、それを聞いている全スプライトが反応できる。
大きなゲームの 基本テクニック！

3.

効果音で ゲームを 気持ちよく

「ポン！」が あるだけで 楽しさ倍増

下のボタンを押して、効果音を 聞いてみよう（音量に注意）。

💡 Scratchでの 追加手順

  1. スプライトを選ぶ → 上の 「音」タブ
  2. 左下の 🔊 マーク → 「音を選ぶ」
  3. 「Pop」「Boing」 など 短い音 を選ぶ
  4. コードに 🟪 Pop の音を 鳴らす を追加
4.

ゲームオーバー画面

新しい スプライトを 追加

「GAME OVER!」と書いたスプライトを 1つ 用意。

🎨 作り方

  1. スプライトを選ぶ → 「ペイント」
  2. テキストで 「GAME OVER!」
  3. 大きく・カラフルに

📜 スクリプト

🟡 旗が押されたとき 🟣 隠す
🟡 「ゲーム終了」 受け取ったとき 🟣 表示する 🟣 最前面へ
