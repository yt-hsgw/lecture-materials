01.

キャリア 診断 コンパス

体感

6問 で 4つ の 道 を 比較

価値観 / リスク許容度 / 興味 などの 6問 に 答える と、 **就職 / 起業 / OSS / 進学** の 4軸 で あなた の 適性 が スコアリング されます。 正解 は ない、 自分 を 知る ヒント として。

💼 就職👑--

安定 / 給与 / 福利厚生 / チーム で 学ぶ。 まず 3年 経験 を 積む 王道。

🚀 起業👑--

自由 / 上限 なし / リスク 高。 失敗 から 学ぶ サイクル が 必要。

🌍 OSS👑--

世界 と 繋がる / 学習 加速 / 実績 が 動く 履歴書 に。 副業 と 相性 良し。

🎓 進学👑--

CS 基礎 / 研究 / 海外 大学院 へ の 入口。 時間 と 学費 が 必要。
02.

GitHub プロフィール ジェネレータ

ハンズオン

「動く 履歴書」 を 30秒 で 作る

あなた の username と 略歴 / スキル / 作品 を 入力 する と、 **GitHub プロフィール README** の Markdown が 生成 されます。 そのまま github.com/<username> リポジトリ に 貼って ください。

04.

OSS コントリビュート 最初の一歩

ハンズオン

7ステップ で 初 マージ まで

各 ステップ を 順番 に 完了 → 次 へ。 PR テンプレ / コミット メッセージ / レビュー対応 文例 を コピペ で 使えます。 「世界 と 繋がる 1コミット」 を 体験しよう。

05.

クイズ で ふり返ろう

3問チャレンジ

Q1. 新卒 エンジニア 採用 で **最も アピール される** のは？
💡 「React と Vue で 迷って ◯◯ の 理由 で React」 の 1文 が 資格10個 より 強い。 「自分の頭 で 決めた」 を 言語化。
Q2. 高校生 で 個人事業主 として 開業 する とき **必須** なのは？
💡 18歳未満 は 法律行為 に 保護者同意 が 必須。 個人事業主 は 開業届 1枚 で 始められる が、 銀行口座 / 契約 で 保護者 が 関わる。
Q3. OSS 初コントリビュート に **適した** Issue ラベル は？
💡 `good first issue` ＝ メンテナ が 初心者向け に 厳選。 typo / 翻訳 / テスト追加 から 始めるのが 王道。
