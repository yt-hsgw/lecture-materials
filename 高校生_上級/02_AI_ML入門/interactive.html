05.

クイズ で ふり返ろう

3問チャレンジ

Q1. 「がん 検査」 AI で **重視 すべき** 指標 は？
💡 見逃し（FN）＝ 治療遅れ で 命 に 関わる。 誤陽性（FP）は 精密検査 で 確認 で OK。 **Recall を 最大化** が 正解。
Q2. RAG が **必要** な 理由 は？
💡 LLM は 学習時点 まで の 知識 のみ。 RAG で 検索結果 を 文脈 に 注入 する と 最新情報 / 社内文書 を 扱える。
Q3. LLM の **幻覚** 対策 で 最も 重要 な のは？
💡 LLM は 平気 で 存在 しない 論文 / API メソッド を 引用 する。 数値 / 出典 は 必ず 一次ソース で 確認。 コード は 実行 + テスト。
06.

きょうのまとめ

おぼえたこと

1

🎯 古典 ML を スキップ しない

実務 8割 は scikit-learn で 解決可能。 LLM が 必要 な シーン を 見極める。

2

💬 プロンプト ＝ 4要素

役割 / タスク / 制約 / 例。 制約 を 明示 する ほど 出力 が 安定。

3

🔮 RAG で 知識 を 拡張

ベクトル DB に 自社 / 最新 文書 を 入れ、 LLM に 文脈 を 渡す。 幻覚 を 抑制。

4

👁️ AI を 過信 しない

幻覚 ＋ バイアス ＋ PII リスク。 最終判断 は 人間、 AI は 補助。
