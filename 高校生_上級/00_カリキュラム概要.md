# 高校生プログラミング塾 ／ 上級コース

## このコースのゴール

高校生・中級 まで で「チームで 本格 Web サービス を 作って 運用する」レベル に 到達 した 受講者が、**社会に 出る 前の 総まとめ** として、 アーキテクチャ・AI / ML・キャリア の 3軸 で 視野を 広げる。 最終回 は **卒業プロジェクト発表会** で、 自分の 作品を **社会に 出す**。

- **アーキテクチャ** の 引き出しを 持つ（モノリス vs マイクロ / DDD / クリーンアーキテクチャ）
- **AI / ML** の 基本を 自分で 触る（scikit-learn / Hugging Face / LangChain）
- **キャリア** の 選択肢を 知る（OSS / 起業 / 就職 / 進学）
- **卒業プロジェクト** を 完成・発表・公開し、 自分の 「初期 ポートフォリオ」 を 持つ

> 高校生・初級・中級 が「技術を 身につける」 だったのに対し、高校生・上級 は **「技術で 何を 作って 社会に 出すか」** が 主役 です。 受講者の **進路 と 自分の 作品** を 結びつけ、 大学・就職・起業 への **最初の 一歩** を 用意します。

---

## 本編スケジュール（全4回・各120分）

| 回 | タイトル | テーマ | ハンズオン |
|----|---------|--------|----------|
| 1 | アーキテクチャ設計 | モノリス vs マイクロ / DDD 入門 / レイヤード / ヘキサゴナル | 自分のアプリを 1案 設計 |
| 2 | AI/ML 入門 | scikit-learn / Hugging Face / LangChain / RAG | 自分のドメインで 1モデル |
| 3 | 起業・OSS・キャリア | プロダクト企画 / 法人化 / 知財 / OSS貢献 / 就職活動 | キャリアシート + GitHub整備 |
| 4 | 卒業プロジェクト発表会 | 自分の作品を 社会に 出す | デモ + 発表 + 公開 |

---

## 各回の狙い

### 第1回｜アーキテクチャ設計
中学生・上級 で 体験 した 「設計 → 実装」 を、 **複数 サービスが 関わる 規模** で 考える。 **モノリス・モジュラーモノリス・マイクロサービス** の トレードオフ、 **DDD（Domain-Driven Design）** の 用語 と モデリング、 **クリーン / ヘキサゴナル アーキテクチャ** の 境界 設計を 紹介。 自分の 卒業プロジェクト の アーキテクチャ図 を 1枚 描く。

### 第2回｜AI/ML 入門
「AIを 使う側」 ＋ 「AIを 作る側」 の 両方を 体験。 **scikit-learn** で 分類・回帰 を 自分の 手元で 動かす。 **Hugging Face** で 既存 モデルを fine-tune（GPU は Colab 推奨）。 **LangChain** で LLM ＋ RAG（Retrieval-Augmented Generation） の 仕組みを 体感。 「AIで 何が できる か」 を 自分の 言葉で 説明できる ように。

### 第3回｜起業・OSS・キャリア
**卒業後** の 選択肢を 並べて 紹介:
- **就職**：新卒 採用の 流れ、 ポートフォリオ の 役割、 技術 面接 の 対策
- **起業**：プロダクト企画、 法人化（合同会社 vs 株式会社）、 知財（特許・商標・著作権）、 資金調達
- **OSS**：人気 リポジトリへの 初コントリビュート、 自分の OSS を 公開
- **進学**：大学・高専・専門学校 の 選び方、 推薦 入試での アピール材料

「正解は ない」 を 強調しつつ、 受講者が **自分の 道を 選ぶ ための 材料** を 提供する。

### 第4回｜卒業プロジェクト発表会
全 3コース・12回（初級 4 + 中級 4 + 上級 3 + 卒業）の **総まとめ**。 受講者 1人 1人が **5〜10分** の 発表 + デモ。 内容例:
- 自分が 作った Web アプリ / モバイル / ゲーム / OSS ライブラリ
- 解決 したい 課題、 使った 技術、 学んだ こと、 次の 一歩

最後 は **修了証 授与 + 紙吹雪 + 集合写真**。 公開可能な 作品 は **コースの 卒業生 ポートフォリオ** として 教室 サイト に 掲載。

## 設計方針

- **正解は ない を 強調**：選択肢を 並べて、 自分で 選ぶ 練習
- **手を 動かす**：話 を 聞く だけ で 終わらない、 第2回 は 必ず 1モデル 動かす
- **公開を 前提**：卒業プロジェクト は 「他人に 見せられる」 状態 を ゴール
- **進路 と 接続**：大学 / 就職 / 起業 / OSS の どれを 選んでも 役立つ 構成
- **AI と 共存**：Copilot / Cursor を 使いつつ、 「自分で 考える」 領域 を 明確に

---

## 危険ケース・注意

- **AI 過信**：LLM の 幻覚 を 体験 し、 ファクトチェック 習慣 を つける
- **個人情報**：AI に 自分や 他人の 個人情報 を 入れない
- **OSS ライセンス**：自分の 作品に 取り込む OSS の ライセンス確認（MIT / Apache / GPL）
- **発表内容**：実在 企業・人物 の 名誉毀損・著作権 に 触れない
- **進路 圧 力**：「就職 / 起業 / 進学 / OSS」の どれが 偉い、 という 順序を つけない
- **未成年 の 契約**：起業・営業 活動 は 保護者 同意 が 必須

## 高校生・中級との 差分メモ

- 中級：「動く プロダクト」 ／ 上級：**「設計可能な アーキテクト」**
- 中級：「既存技術を 使う」 ／ 上級：**「AI / ML を 自分で 動かす」**
- 中級：「教室内 PR」 ／ 上級：**「OSS / 起業 / 就職」 の 視野**
- 中級：「サービス公開」 ／ 上級：**「卒業プロジェクト を 社会に 出す」**

## 全 4コース（高校生編） まとめ

高校生 全12回（初級 4 + 中級 4 + 上級 4） を 修了すると、 以下 が できるように なります:

1. **モダンな 開発環境** を コード化 して 再現できる
2. **型・テスト・CI** が 当たり前 の コードを 書ける
3. **チーム** で プロダクト を 動かせる
4. **DB / キャッシュ / 監視** で 規模 を 支えられる
5. **アーキテクチャ** の 引き出し を 持つ
6. **AI / ML** を 自分で 動かせる
7. **キャリア** の 選択肢 を 知っている
8. **公開可能 な ポートフォリオ作品** を 1つ 持つ

これで 大学 1〜2年生、 新卒 エンジニア、 個人事業主 として **初日 から 戦力** に なれる レベルです。
